# Museum Reciprocity

Find ASTC science centers and AZA zoos/aquariums with reciprocal admission. Hub SPA at **`/museums`**.

Search by city, filter by radius, and switch between a card grid and a Leaflet map. Filters stay in `localStorage`. Data is bundled JSON in `src/museums/data/`:

- ASTC Travel Passport (May 1, 2026 – October 31, 2026)
- AZA Reciprocal Admissions (May 2026 – April 2027)
